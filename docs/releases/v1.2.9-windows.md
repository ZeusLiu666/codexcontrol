# CodexControl 1.2.9 · Windows x64

[English](#english) | [简体中文](#简体中文)

## English

This Windows update adds a clearer application icon and Refresh button, and fixes adding accounts when only Codex Desktop is installed.

### Changes

- Use Codex Desktop's existing bundled command without installing a separate CLI or changing PATH. Both versioned local directories and registered Microsoft Store/MSIX packages are supported.
- Discover the command again for each sign-in so Desktop updates can change its path. Validate the executable and its version before using it; skip graphical applications and failed or timed-out probes.
- Show a connected circular arrow, a visible button surface, and the text **Refresh** in the top-right corner. Preserve keyboard access with **Ctrl+R** and fit narrow windows and larger text scales.
- Update the application, desktop, taskbar, and tray icon with a simpler mint control mark and clean edges at small sizes. Tray status colors remain available.

### Downloads and upgrade

- `CodexControl-1.2.9-windows-x64-Setup.exe`: current-user installer for Windows 10 x64 1809 or later and Windows 11 x64. The destination can be changed during installation; a desktop shortcut is optional.
- `CodexControl-1.2.9-windows-x64-portable.zip`: extract and run `CodexControl.exe`, with no separate Python installation.
- `SHA256SUMS-windows.txt`: SHA-256 checksums for both Windows downloads.

Quit CodexControl before upgrading. Existing accounts and settings remain in `%APPDATA%\CodexControl`; uninstalling preserves that directory. The portable edition uses the same application-data location.

### Validation and scope

The Windows release workflow runs the source privacy gate and complete Windows regression suite, then builds the executable, installer, and portable archive from the tagged source's commit using pinned build dependencies. Checksums are verified again before the draft release is published.

Local validation covers command discovery without a CLI on PATH, Desktop's bundled `--version` and `login --help` commands, the updated interface, and narrow-window/text-scale layouts. Real account sign-in and switching are not part of these automated checks.

This is a prerelease. Windows executables are unsigned. No macOS build is included or claimed to have been retested; existing macOS downloads remain available in [1.2.8](https://github.com/ZeusLiu666/codexcontrol/releases/tag/v1.2.8-zeusliu.1).

## 简体中文

本次 Windows 更新带来更清楚的应用图标和刷新按钮，并修复仅安装 Codex Desktop 时无法添加账号的问题。

### 更新内容

- 直接复用 Codex Desktop 已有的内置命令，无需另装 CLI 或修改 PATH，支持本机版本目录和已注册的 Microsoft Store/MSIX 安装。
- 每次登录重新查找命令，适应桌面版更新后的路径变化；使用前校验可执行文件及版本，跳过图形界面程序、失败或超时的探测结果。
- 右上角使用连接完整的圆形箭头、可见按钮底色和 **Refresh** 文字；保留 **Ctrl+R** 快捷键，并兼容窄窗口和较大文字缩放。
- 更新应用、桌面、任务栏与托盘图标，以简洁薄荷绿控制标志提高小尺寸辨识度；托盘状态配色继续保留。

### 下载与升级

- `CodexControl-1.2.9-windows-x64-Setup.exe`：适用于 Windows 10 x64 1809 及以上和 Windows 11 x64 的当前用户安装包，可修改安装位置、选择创建桌面快捷方式。
- `CodexControl-1.2.9-windows-x64-portable.zip`：解压运行 `CodexControl.exe`，无需另装 Python。
- `SHA256SUMS-windows.txt`：Windows 安装包和便携包的 SHA-256 校验值。

升级前请退出 CodexControl。现有账号和设置保存在 `%APPDATA%\CodexControl`；卸载会保留此目录，便携版也使用同一应用数据位置。

### 验证范围

Windows 发布流程先执行源码隐私检查与完整回归测试，再从版本标签对应的源码提交、使用固定版本构建依赖生成程序、安装包和便携包；草稿 Release 正式发布前再次校验附件哈希。

本地验证覆盖 PATH 中没有 CLI 时的命令发现、桌面版内置命令的 `--version` 与 `login --help`、更新后的界面，以及窄窗口和文字缩放布局。自动检查未使用真实账号执行登录或切换。

本版本保持预发布状态，Windows 程序未进行代码签名。本次不附带 macOS 构建，也不声称重新完成了 macOS 测试；现有 macOS 下载保留在 [1.2.8](https://github.com/ZeusLiu666/codexcontrol/releases/tag/v1.2.8-zeusliu.1)。
