### Release attachments

The [Release](https://github.com/ZeusLiu666/codexcontrol/releases/tag/v1.2.8-zeusliu.1) has full English and Chinese release notes and a bilingual `PRIVACY-AND-TEST-REPORT.txt`. Windows packages include the bilingual Windows README, project license, and third-party notice guide. macOS DMG/PKG include the bilingual installation guide, project license, and NOTICE. The sanitized source archive contains the documentation listed above.

### Machine-readable and legal formats

Requirements and robots files have paired explanatory comments; the web manifest has a bilingual description. Package names, code, commands, configuration keys, binary formats, and SHA-256 checksum lines retain their required syntax.

Canonical project/native license originals are retained verbatim, with clearly labeled unofficial Chinese reference translations. The generated third-party notice file has a complete bilingual project-authored guide. Its external legal annex retains collected runtime license originals in their original language; the guide does not claim to translate every external clause or replace a license. Required author/copyright notices are preserved.

### 机器可读与法律文本格式

依赖清单和 robots 文件使用成对说明注释，网页 manifest 使用双语描述。包名、代码、命令、配置键、二进制格式及 SHA-256 校验行保留各自所需的语法。

项目及原生组件的正式许可证原文逐字保留，并附明确标注为非官方的中文参考译文。自动生成的第三方声明具有完整双语的项目导读；其中外部法律附录仍按原语言收录运行时许可证原文，导读不宣称已翻译每一项外部条款，也不替代许可证。必要作者与版权归属保留。
