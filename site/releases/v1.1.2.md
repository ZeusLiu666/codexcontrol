# CodexControl 1.1.2

[English](#english) | [中文](#中文)

## English

Historical release notes: these describe this version at release time. Features and distribution details may have changed in later releases.

### Highlights

- Fixed the packaged Windows switch-account regression that prevented Codex Desktop from restarting into the newly selected session
- Added a regression test that protects the hidden PowerShell launcher behavior

### Windows Fix

- Removed `DETACHED_PROCESS` from the hidden PowerShell restart helper launch flags
- Kept the direct hidden PowerShell path so packaged restarts still avoid a visible console flash
- Added coverage that asserts the launcher keeps `CREATE_NO_WINDOW` and `CREATE_NEW_PROCESS_GROUP` while excluding `DETACHED_PROCESS`

### Included Assets

- `CodexControl-macos.zip`
- `CodexControl-macos.zip.sha256`
- `CodexControl-windows.zip`
- `CodexControl-windows.zip.sha256`

### Notes

- Public repository assets continue to use demo-only account data

## 中文

历史版本说明：以下内容描述该版本发布时的情况；功能与分发方式可能已在后续版本中调整。

### 主要更新

- 修复 Windows 打包版本切换账号时的回归问题，该问题曾阻止 Codex Desktop 重新启动并进入新选中的会话。
- 增加回归测试，防止隐藏 PowerShell 启动器的行为发生退化。

### Windows 修复

- 从隐藏 PowerShell 重启辅助程序的启动标志中移除 `DETACHED_PROCESS`。
- 保留直接启动隐藏 PowerShell 的方式，使打包版本重启时仍不会闪现可见控制台。
- 增加测试，断言启动器保留 `CREATE_NO_WINDOW` 和 `CREATE_NEW_PROCESS_GROUP`，同时不使用 `DETACHED_PROCESS`。

### 包含的附件

- `CodexControl-macos.zip`
- `CodexControl-macos.zip.sha256`
- `CodexControl-windows.zip`
- `CodexControl-windows.zip.sha256`

### 说明

- 公开仓库资源继续仅使用演示账号数据。
