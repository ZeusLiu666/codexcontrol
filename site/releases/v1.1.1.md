# CodexControl 1.1.1

[English](#english) | [中文](#中文)

## English

Historical release notes: these describe this version at release time. Features and distribution details may have changed in later releases.

### Highlights

- Synced the Windows app with the latest stable implementation from the maintained dev copy
- Promoted the newer Windows presentation logic for account sorting and active-account detection
- Prepared the repository and website metadata for the current GitHub release line

### Windows Improvements

- Added a dedicated presentation layer for sorting accounts by practical usability
- Fixed active-account matching so shared provider IDs do not mark multiple accounts as active
- Added brand icon and presentation tests to strengthen the Windows validation suite
- Tracked packaged Windows icon assets directly in the repository

### Distribution Notes

- GitHub Releases now target `v1.1.1` for both macOS and Windows assets
- The site and release references now point at the current release line
- Sparkle-based macOS auto-update plumbing has been removed from the app and release chain

### Notes

- Public assets still use demo-only account data
- Local account auth data, snapshots, and managed homes remain out of the repository

## 中文

历史版本说明：以下内容描述该版本发布时的情况；功能与分发方式可能已在后续版本中调整。

### 主要更新

- 将 Windows 应用与受维护开发副本中的最新稳定实现同步。
- 引入新版 Windows 展示逻辑，用于账号排序和当前账号识别。
- 为当时的 GitHub 发布系列准备仓库及网站元数据。

### Windows 改进

- 增加独立展示层，按实际可用性对账号排序。
- 修复当前账号匹配，防止共享服务商 ID 导致多个账号被标记为当前账号。
- 增加品牌图标与展示逻辑测试，增强 Windows 验证测试集。
- 将 Windows 打包图标资源直接纳入仓库版本管理。

### 分发说明

- GitHub Releases 中的 macOS 和 Windows 附件均面向 `v1.1.1`。
- 网站与发布引用指向当时的发布系列。
- 从应用和发布流程中移除基于 Sparkle 的 macOS 自动更新机制。

### 说明

- 公开资源仍仅使用演示账号数据。
- 本地账号认证数据、快照及受管理账号目录继续排除在仓库之外。
