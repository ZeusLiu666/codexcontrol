WINDOWS

System tray and account window

Windows 10 x64 1809 or later, or Windows 11 x64. The installer and portable package need no separate Python installation.

  • Current-user installation with optional start at sign-in
  • Extract and run the portable package
  • Save and restore Desktop session state when switching accounts

macOS

Menu bar and desktop widgets

macOS 14 or later. Current releases provide an Apple Silicon arm64 build. See the release notes for signing and compatibility details.

  • Native SwiftUI / AppKit implementation
  • Account quotas and local Token statistics
  • macOS desktop Widget
Download DMG / PKG ↗

Both versions use the Codex CLI installed on your computer to sign in. Switching accounts may restart Codex Desktop, so save your work first. Each release's notes document its test scope and checksums.

Quotas, accounts, and usage in one place

Live quota tracking

Read quotas from OpenAI and show separate 5-hour and 7-day windows with reset times when the API provides them.

Local account management

Add, sign in again, refresh, and switch accounts, and see the current sign-in state.

Incremental Token statistics

Establish a local log baseline on first run, then count new events and show usage over the last 7 days.

Privacy

Accounts stay local. Protect sensitive files.

Release packages contain no preconfigured accounts, authentication files, private SSH configurations, or runtime logs. Remote SSH statistics are disabled by default and require the user's own configuration.

Quota queries and credential refreshes communicate with OpenAI. Local accounts, tokens, backups, and session caches are not guaranteed to have additional encryption. Do not upload application data directories or screenshots containing sensitive information.

额度、账号和用量，一起查看

实时额度

从 OpenAI 读取额度；接口提供时分别展示 5 小时与 7 天窗口及重置时间。

本地账号管理

添加、重新登录、刷新和切换账号，查看当前登录状态。

增量 Token 统计

首次运行建立本地日志基线，随后统计新增事件，展示近 7 天用量。

隐私边界

账号留在本机，敏感文件需要保护。

发布包不包含预置账号、认证文件、私人 SSH 配置或运行日志。远程 SSH 统计默认关闭，由使用者主动配置。

程序查询额度和刷新凭据时需要与 OpenAI 通信。本地账号、令牌、备份和会话缓存不保证额外加密，请勿上传应用数据目录或未经脱敏的截图。
